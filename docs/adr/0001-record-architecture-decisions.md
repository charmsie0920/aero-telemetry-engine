# ADR 0001: Record architecture decisions

## Status
Accepted

## Context
This project's key technical decisions are tracked in the Decision Log (PRD Section 11). Significant decisions are also recorded here as individual ADRs for easier reference during interviews and code review.

## Decision
Use lightweight ADRs in `docs/adr/`, one file per decision, numbered sequentially. Each ADR states status, context, decision, and consequences.

## Consequences
Decisions and their reasoning are discoverable independent of the PRD, and can be linked from code/PRs.
